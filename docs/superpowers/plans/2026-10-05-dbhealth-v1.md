# dbhealth v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Someone points `dbhealth` at a Postgres connection string and, within a minute, control shows whether that database is serving, how close it is to its limits, and whether its tables are current.

**Architecture:** One Go binary, `dbhealth`, with three parts: config (one file, a list of databases), a Postgres collector (probe, resources, tables, replication), and a reporter that signs one TurboStats bundle per database per interval and POSTs it to control. The bundle's `database` section is a type in `sql-flow`'s `turbostats/wire` package, shared with control. Control learns a second kind of instance.

**Tech Stack:** Go 1.26, `github.com/jackc/pgx/v5`, `github.com/turbolytics/sql-flow/turbostats/wire` (Ed25519 signing, the bundle), testcontainers-go for Postgres in tests, `gopkg.in/yaml.v3`.

**Spec:** `docs/superpowers/specs/2026-10-05-turbostats-database-section-design.md` (merged in sql-flow #441; this copy is for the executor).

## Global Constraints

- **Facts, never judgments.** The reporter sends timestamps, counts and limits. No field in the bundle says stale, degraded or healthy.
- **No credentials in the bundle.** `target` is `host:port/database`. The DSN never leaves the process. Logs never print it.
- **One instance per endpoint.** Each entry in `databases` is one instance id, one bundle per interval. `cluster` groups them.
- **Estimates by default, exact by choice.** `rows` is `n_live_tup` unless the table's config says `rows: exact`, and exact counts run on `rows_exact_interval_seconds`, never every interval. `rows_exact` in the bundle says which was sent.
- **One table's failure never hides the others.** A query that fails lands in `collection.errors` with its table name; the bundle still sends.
- **A failed probe sends `probe` alone.** Nothing else in `database` is present when the probe failed.
- **Postgres only in v1.** The config's `kind` is validated; `mysql`, `mongo`, `snowflake` and `redshift` are refused at start with "not in this version". Comparisons are out.
- **The cost of watching is bounded and reported.** `collection.queries` and `collection.duration_ms` are in every bundle.
- **Prose** per sql-flow-control's `CLAUDE.md`: active voice, one idea per sentence, no hedging. Commit messages name the defect, the fix and the evidence.
- **Every PR is cut from `main`, reviewed, and merged before the next starts.** Push with an explicit refspec.

## Review Focus

1. **A DSN with a password in the config file**, not the environment. The bundle and every log line must still carry only `host:port/database`. Test: `redactedTarget` over a DSN with a password, a URL and a key=value DSN (Task 3).
2. **A role that cannot read `pg_stat_activity` rows for other users.** `connections.used` must be absent, and `collection.errors` must say which view, not report `used: 1` as if true. Test: the testcontainers role without `pg_read_all_stats` (Task 4).
3. **A discovered table with no timestamp column.** It is watched for rows and size with no `newest_at`, not skipped. Test: discovery over a schema with such a table (Task 4).
4. **A table dropped between discovery and collection.** The error lands in `collection.errors`, the interval continues. Test: drop a table after discovery, before the collect (Task 4).
5. **Control's clock and the reporter's disagree by minutes.** `sent_at` is the reporter's clock, as for every bundle, and control's skew handling is unchanged; nothing in this plan compares the two. Test: none needed here; noted so no task adds a comparison.

`turbostats/wire/database.go`:

```go
package wire

import "time"

// Database is the section a dbhealth reporter sends: one database endpoint,
// probed and measured. Facts only: timestamps, counts and limits. The
// receiver judges them. Fields a kind cannot provide are absent, not zero.
//
// Spec: docs/superpowers/specs/2026-10-05-turbostats-database-section-design.md.
type Database struct {
	// Kind is postgres, mysql, mongo, snowflake or redshift.
	Kind string `json:"kind"`
	// Target is host:port/database. Never a DSN: it carries no credential.
	Target string `json:"target"`
	// Cluster groups a primary with its replicas. Absent when not configured.
	Cluster       string `json:"cluster,omitempty"`
	ServerVersion string `json:"server_version,omitempty"`

	// Probe is always present. When it failed, nothing below it is.
	Probe DatabaseProbe `json:"probe"`

	Resources   *DatabaseResources   `json:"resources,omitempty"`
	Tables      []DatabaseTable      `json:"tables,omitempty"`
	Replication *DatabaseReplication `json:"replication,omitempty"`
	Collection  DatabaseCollection   `json:"collection"`
}

// DatabaseProbe is one round trip per interval: is it serving, and how fast.
type DatabaseProbe struct {
	OK        bool       `json:"ok"`
	LatencyMs int64      `json:"latency_ms"`
	LastOKAt  *time.Time `json:"last_ok_at,omitempty"`
	// ConsecutiveFailures counts probes failed in a row, 0 when OK.
	ConsecutiveFailures int `json:"consecutive_failures"`
	// Error is the class of the latest failure: refused, timeout, auth or
	// other. Empty when OK.
	Error string `json:"error,omitempty"`
}

// DatabaseResources is how close the database is to its limits. Each field
// is absent when the kind, or the role, cannot read it.
type DatabaseResources struct {
	Connections *DatabaseConnections `json:"connections,omitempty"`
	// SizeBytes is this database on disk.
	SizeBytes *int64 `json:"size_bytes,omitempty"`
	// OldestTransactionSeconds is the age of the oldest open transaction;
	// one idle in transaction holds vacuum back.
	OldestTransactionSeconds *int64          `json:"oldest_transaction_seconds,omitempty"`
	Memory                   *DatabaseMemory `json:"memory,omitempty"`
}

type DatabaseConnections struct {
	Used    int `json:"used"`
	Max     int `json:"max"`
	Waiting int `json:"waiting"`
}

// DatabaseMemory carries settings, not usage: a database does not know the
// host's memory from SQL.
type DatabaseMemory struct {
	SharedBuffersBytes int64 `json:"shared_buffers_bytes"`
}

// DatabaseTable is one watched table's freshness, size and row count.
type DatabaseTable struct {
	Name            string `json:"name"`
	FreshnessColumn string `json:"freshness_column,omitempty"`
	// NewestAt is max(FreshnessColumn). Absent when the table has none.
	NewestAt *time.Time `json:"newest_at,omitempty"`
	// Rows is an estimate unless RowsExact, which says count(*) ran.
	Rows         *int64     `json:"rows,omitempty"`
	RowsExact    bool       `json:"rows_exact"`
	SizeBytes    int64      `json:"size_bytes"`
	LastVacuumAt *time.Time `json:"last_vacuum_at,omitempty"`
	CheckedAt    time.Time  `json:"checked_at"`
}

// DatabaseReplication is measured from this endpoint's side. A replica
// reports how far behind what it serves is; a primary reports what it knows
// about each replica.
type DatabaseReplication struct {
	// Role is primary or replica.
	Role           string     `json:"role"`
	LagSeconds     *float64   `json:"lag_seconds,omitempty"`
	LastReplayedAt *time.Time `json:"last_replayed_at,omitempty"`
	Upstream       string     `json:"upstream,omitempty"`
	// Replicas is a primary's view of each replica.
	Replicas []DatabaseReplica `json:"replicas,omitempty"`
}

type DatabaseReplica struct {
	Name       string   `json:"name"`
	LagSeconds *float64 `json:"lag_seconds,omitempty"`
	State      string   `json:"state,omitempty"`
}

// DatabaseCollection is what the interval cost, so the receiver can show
// the price of watching, and every per-table failure, so one table the
// role cannot read does not hide the others.
type DatabaseCollection struct {
	Queries    int             `json:"queries"`
	DurationMs int64           `json:"duration_ms"`
	Errors     []DatabaseError `json:"errors"`
}

type DatabaseError struct {
	Table string `json:"table,omitempty"`
	Error string `json:"error"`
}
```

- [ ] **Step 1: The queries**

Each verified on Postgres 18 during planning. The collector counts every query it runs into `collection.queries`.

| Field | SQL |
|---|---|
| probe | `SELECT 1`, timed; the error class from the pgx error: `refused` (connection refused / no such host), `timeout` (context deadline), `auth` (SQLSTATE `28xxx`), else `other` |
| server_version | `SHOW server_version` |
| connections | `SELECT count(*) FILTER (WHERE backend_type='client backend'), current_setting('max_connections')::int, count(*) FILTER (WHERE wait_event_type='Lock') FROM pg_stat_activity` |
| size_bytes | `SELECT pg_database_size(current_database())` |
| oldest_transaction_seconds | `SELECT COALESCE(EXTRACT(EPOCH FROM now() - min(xact_start))::bigint, 0) FROM pg_stat_activity WHERE xact_start IS NOT NULL AND backend_type='client backend'` |
| memory.shared_buffers_bytes | `SELECT pg_size_bytes(current_setting('shared_buffers'))` |
| discovery | `WITH want(col, pri) AS (VALUES ($1,1),($2,2),…) SELECT DISTINCT ON (n.nspname, c.relname) n.nspname, c.relname, w.col FROM pg_class c JOIN pg_namespace n ON n.oid=c.relnamespace LEFT JOIN information_schema.columns ic ON ic.table_schema=n.nspname AND ic.table_name=c.relname AND ic.data_type LIKE 'timestamp%' LEFT JOIN want w ON w.col=ic.column_name WHERE c.relkind='r' AND n.nspname = ANY($schemas) ORDER BY n.nspname, c.relname, w.pri NULLS LAST` — a table with no matching column comes back with `col` NULL and is still watched; `exclude` globs are applied in Go with `path.Match`; the first `max_tables` after sorting by name are kept and the rest logged once |
| table estimate, size, vacuum | `SELECT s.n_live_tup, pg_total_relation_size(c.oid), GREATEST(s.last_vacuum, s.last_autovacuum) FROM pg_class c JOIN pg_namespace n ON n.oid=c.relnamespace LEFT JOIN pg_stat_user_tables s ON s.relid=c.oid WHERE n.nspname=$1 AND c.relname=$2` |
| table exact | `SELECT count(*) FROM <quoted schema>.<quoted table>` |
| table newest_at | `SELECT max(<quoted col>) FROM <quoted schema>.<quoted table>` |
| replication | `SELECT pg_is_in_recovery(), CASE WHEN pg_is_in_recovery() THEN EXTRACT(EPOCH FROM now() - pg_last_xact_replay_timestamp()) END, pg_last_xact_replay_timestamp()`; on a primary also `SELECT application_name, state, EXTRACT(EPOCH FROM replay_lag) FROM pg_stat_replication` and `role` is `primary` with `replicas` from it (absent when none, and then the whole section is absent) |
